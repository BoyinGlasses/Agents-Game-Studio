# Narrative Rules

- Cross-reference every new lore entry against existing canon to prevent contradictions.
- Tag every lore entry with a canon status: `Established` | `Provisional` | `Under Review`.
- Match character dialogue to the character's defined voice profile (`design/narrative/`).
- Keep world rules (what is possible, impossible, or costly) explicit and internally consistent.
- Document the true underlying answer for every mystery, even if players never uncover it directly.
- Ensure faction goals, resources, relationships, and power structures remain internally logical.
- Author localization-ready text: avoid untranslatable idioms or puns without notes, and use named placeholders (`{player_name}`, `{item_count}`) instead of positional concatenation.
- Respect dialogue box line budgets (default <= 120 characters per beat unless `project.yaml` / UI spec sets another limit).
